> SMS items need the MiMSMS whitelist approved first. Steadfast items need your
> Steadfast merchant API keys in `.env` (`STEADFAST_API_KEY`, `STEADFAST_SECRET_KEY`).

- [ ] First visit (or clear localStorage): phone popup → code screen shows 6 boxes.

## #71 — Choose verification method at signup

- [ ] `/account/register`: below the password field there's "Send my verification
      code by — **SMS to my phone** / **Email**".
- [ ] Choose SMS → Next → "We texted a 6-digit code to +8801•••••XXX" and the SMS
      arrives (after MiMSMS approval).

## #72 — Promo SMS + customer export (admin)

- [ ] `/admin/customers`: table now shows phone numbers with checkboxes.
- [ ] **Send promo SMS** → composer: type a message (segment counter switches
      160→70 chars when you type Bengali), pick "All customers with a phone" or
      selected rows, see recipient count + cost estimate, type `SEND <count>`
      exactly → Send → toast "Sent to X, failed Y" (SMS credit is spent!).
- [ ] **Export CSV** → downloads customers-YYYY-MM-DD.csv, opens clean in Excel.

## #73 — Order confirmation SMS

- [ ] Place a COD order with a real BD phone → SMS "Maison: order MSN-000XX
      confirmed (Tk …). Track: …" arrives alongside the email.
- [ ] Pay-online (sandbox) order → same, with "confirmed & paid".

## #74 — Bulk product upload (Excel)

- [ ] `/admin/products/import` (sidebar → Catalog → Import Products).
- [ ] **Download template** → open in Excel: Instructions sheet + Products sheet
      with dropdowns (Division, Category, Collection, Size Set, Offer Type) and
      2 grey EXAMPLE rows.
- [ ] Fill 1–2 rows (copy the examples), save, **upload** → preview table shows
      green valid rows (bad rows show exact errors in red).
- [ ] **Import N valid products** → success summary; products appear in
      `/admin/products` and on the storefront.

## #75 — Steadfast courier (after adding your API keys)

- [ ] Open a processing order in `/admin/orders` → Ship step shows
      **Send to Steadfast** above the manual tracking form.
- [ ] Click it → order becomes Shipped with a Steadfast tracking code; a
