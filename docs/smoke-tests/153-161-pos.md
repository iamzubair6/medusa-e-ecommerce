## 1. Counter sign-in + roles (#153) [E2E ✓]
- [ ] /pos (signed out) redirects to /pos/login. Sign in with the STAFF user →
      the fullscreen counter opens (no storefront navbar, no admin sidebar).
- [ ] With the STAFF login, open /admin → you are bounced to /pos (staff can
      never operate the admin panel).
- [ ] Being signed into /admin as owner does NOT open /pos by itself — the
      counter has its own login (separate cookie). Sign into /pos as the owner
      too: an **Admin** badge shows in the header, plus a "Day report" link.

## 2. Find products + live stock (#154) [E2E ✓]

## 5. Online orders decrement stock too (#156 — the closed gap)
- [ ] Place a normal ONLINE order (COD) for a tracked size → after checkout,
      that size's stock drops on the PDP/admin exactly like a counter sale.
      (Before this build, online orders never touched stock.)

## 6. Oversell guard (#156)

      it → Charge → a dialog warns "1 tracked, selling 2" with **Sell anyway**.
- [ ] Sell anyway → order completes; stock floors at 0 (never negative).
