# Tests #153–#161 — POS (point of sale): sell, stock sync, receipts, returns, Z-report

> Local: http://localhost:3200/pos · Production: https://<your-domain>/pos
> (the `pos.<domain>` subdomain is optional later — phase 3).
> You need one STAFF user: /admin/users → Add user → role **Staff — POS counter only**.
> Production note: run the cms `db push` first (adds the STAFF role to the live DB).

## 1. Counter sign-in + roles (#153)
- [ ] /pos (signed out) redirects to /pos/login. Sign in with the STAFF user →
      the fullscreen counter opens (no storefront navbar, no admin sidebar).
- [ ] With the STAFF login, open /admin → you are bounced to /pos (staff can
      never operate the admin panel).
- [ ] Being signed into /admin as owner does NOT open /pos by itself — the
      counter has its own login (separate cookie). Sign into /pos as the owner
      too: an **Admin** badge shows in the header, plus a "Day report" link.

## 2. Find products + live stock (#154)
- [ ] Type part of a product name → cards appear with photo, price, total stock.
- [ ] Type a full SKU (product editor shows them, e.g. HANDLE-COLOR-SIZE) → the
      product appears. (A USB barcode scanner types exactly this + Enter.)
- [ ] Open a product → colour chips + size grid show **live** quantities
      ("3 left"); a size at 0 is disabled and struck through.
- [ ] Nonsense query shows "Nothing matches" (no crash, no spinner stuck).

## 3. Sell — cash (#155, #156, #157)
- [ ] Add 2 items, one of them twice (the line gets a ×2 stepper, not a dup).
- [ ] Charge Cash → success screen shows the total and an **MSN-xxxxx** order
      number in the same sequence as online orders.
- [ ] **Stock synced**: open that product's PDP on the storefront — the sold
      size shows reduced/sold-out availability immediately. /admin/restock and
      Stock alerts see the same number.
- [ ] The order appears in /admin/orders with payment method `pos_cash`.
- [ ] Print receipt → 80mm layout: logo, date/time, order no, "Sold by",
      each line with colour/size × qty, total, THANK YOU footer.
- [ ] "New sale" clears the cart and search.

## 4. Sell — bKash/Nagad + TXN id (#155)
- [ ] Pick bKash → the Charge button stays disabled until a TXN id is entered.
- [ ] Complete the sale → the TXN id prints on the receipt and shows in the
      order metadata (and later on the Z-report row).

## 5. Online orders decrement stock too (#156 — the closed gap)
- [ ] Place a normal ONLINE order (COD) for a tracked size → after checkout,
      that size's stock drops on the PDP/admin exactly like a counter sale.
      (Before this build, online orders never touched stock.)

## 6. Oversell guard (#156)
- [ ] Set a size's stock to 1 in the product editor. At the counter, add ×2 of
      it → Charge → a dialog warns "1 tracked, selling 2" with **Sell anyway**.
- [ ] Sell anyway → order completes; stock floors at 0 (never negative).

## 7. Promo codes + manual discount (#158)
- [ ] Enter a live promo code from /admin/discounts → complete the sale → the
      success screen + receipt show the discount and the reduced total.
- [ ] STAFF login: there is NO manual-discount field. Owner (admin) login: set
      Manual discount 10% → the estimated total updates; after charging, the
      order total reflects it.

## 8. Customer attach (#161)
- [ ] Enter the phone of an existing customer → Find → their name appears as
      "Attached". Complete the sale → the order shows under that customer in
      /admin/customers → detail (and in their storefront order history).
- [ ] An unknown phone shows "selling as walk-in" and still completes.

## 9. Returns & restock (#159 — admin only)
- [ ] /pos → Orders → enter the receipt's MSN number → the sale opens with its
      lines. As STAFF: no refund button ("Returns need an admin sign-in").
- [ ] As admin: set Return ×1 on a line → Refund & restock → confirm → toast.
- [ ] The size's stock went UP by 1 (product editor / PDP), and the order now
      shows the refund entry with who processed it.

## 10. Z-report + dashboard split (#160 — admin only)
- [ ] /pos → Day report: today's tiles (Sales, Gross, Cash, bKash, Nagad,
      Refunded, Net), every sale as a row with time/cashier/method/TXN, the
      refund listed, and per-cashier totals. Print gives a clean page.
- [ ] Pick an older date → empty day shows "No counter sales this day."
- [ ] /admin dashboard → the Revenue card now reads "Online ৳X · POS ৳Y".
